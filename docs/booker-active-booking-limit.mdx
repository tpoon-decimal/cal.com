---
title: "Booker Active Booking Limit"
description: "Control how many upcoming bookings a single booker can have for a specific event type."
---

The Booker Active Booking Limit lets you set the maximum number of upcoming bookings a single person (booker) can hold for a specific event type at the same time. This helps ensure fair access to your availability by preventing one attendee from reserving multiple slots.

## How It Works

When you enable an active booking limit on an event type, Cal.com tracks how many future, accepted bookings each booker currently has for that event type. Once a booker reaches the limit, they cannot schedule another booking of this type until one of their existing bookings is completed or canceled.

The limit is per event type and is based on the booker's email address. A booker who has reached the limit on one event type can still book other event types.

## What Counts Toward the Limit

Only **future bookings** with an **Accepted** status count toward the active booking limit. The following do not count:

- **Canceled bookings** — a canceled booking no longer counts toward the limit.
- **Past bookings** — bookings whose start time has already passed do not count.

The limit resets automatically as bookings are completed or canceled.

## Setting the Limit

You can configure the Booker Active Booking Limit in your event type's advanced settings. Set the maximum number of active bookings a booker can have for that event type.

You can also choose whether to offer the booker the option to reschedule their last active booking to the chosen time slot when the limit is reached.

<Note>
This feature is not available for recurring event types.
</Note>
